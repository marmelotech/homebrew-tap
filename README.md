# Marmelotech Homebrew Tap

Official Homebrew tap for Marmelotech and Shepherd Platform developer tooling.

## Installation

To install **Shepherd CLI**:

```bash
brew tap marmelotech/tap
brew install shepherd
```

Or as a direct one-liner:

```bash
brew install marmelotech/tap/shepherd
```

## Updating

```bash
brew update
brew upgrade shepherd
```
